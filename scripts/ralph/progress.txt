## Codebase Patterns
- This is Next.js 16 with TailwindCSS v4 — no tailwind.config.ts; use @theme inline {} in globals.css for custom tokens
- TailwindCSS v4 token syntax: `--color-terminal: #0a0a0a` in @theme, then use as `bg-[#0a0a0a]` or via CSS vars
- All interactive components (useState, useEffect, onClick, localStorage) must have "use client" directive
- App is at /workspace/app — run `cd /workspace/app && npx tsc --noEmit` for typecheck
- Commit requires `-c gpg.format=openpgp -c commit.gpgsign=false` flags to bypass GPG signing (place flags BEFORE the subcommand: `git -c ... commit`)
- JetBrains Mono loaded via next/font/google as JetBrains_Mono (underscore in import name)
- dev-browser skill is NOT available; note "manual browser verification needed" in progress
- Task types defined in app/app/types/task.ts; useTaskStore hook in app/app/hooks/useTaskStore.ts
- Use crypto.randomUUID() for generating task IDs (available in modern browsers and Node 18+)
- localStorage key for tasks: "task_os_tasks"
- @dnd-kit/core is installed; DndContext wraps the board; useDroppable per column; useDraggable per card
- Extract DroppableColumn as a separate component (not inline in .map()) because hooks can't be called in callbacks
- DragOverlay renders the drag ghost; pass task data via `data` prop on useDraggable
